# code

This repository contains multiple projects:

## Floor Plan Application

An interactive React application that displays a floor plan with animations. Located in the `floor-plan-app/` directory.

### Quick Start

```bash
cd floor-plan-app
npm install
npm run dev
```

Visit http://localhost:5173 to view the application.

### Building for Production

```bash
cd floor-plan-app
npm run build
npm run preview
```

See [floor-plan-app/README.md](floor-plan-app/README.md) for more details.

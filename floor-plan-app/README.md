# Floor Plan App

A React application that displays an interactive floor plan with animations using Framer Motion.

## Features

- Interactive floor plan visualization
- Smooth animations using Framer Motion
- Responsive design with Tailwind CSS
- Multiple rooms: bedrooms, kitchen, dining, toilets, and staircase

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
